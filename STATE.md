- 2026-08-19: **Whole repo was committed with CRLF line endings — now normalized to LF (commit a009577).** *The lesson:* the previous machine committed Windows line endings into git, which Python and Dockerfiles tolerate but **shell scripts do not**: the shebang `#!/usr/bin/env sh` became `#!/usr/bin/env sh\r`, so `env` failed with `env: 'sh\r': No such file or directory` at container start — before the entrypoint's `mkdir` or `exec "$@"` ever ran.
